# 108 課綱素養導向評量設計師

依教材、年段、評量目的與十二年國教課綱，設計或審查可追溯、可驗證、可直接輸出的素養導向評量。

目前版本：**3.7.17**（2026-10-09）

版本變更紀錄另見 [HISTORY.md](HISTORY.md)。

## 主要功能

- 分析教材核心概念、能力、迷思與評量邊界。
- 查證並對應十二年國教課綱、學習表現、學習內容與核心素養。
- 題型多選、逐類題數或 AI 自動分配設定均包含在啟動時自動顯示的一次性需求表單中。
- 只要提出生成評量題目的要求，就自動顯示一次填寫的完整需求表單；訊息與附件中的已知資料會預填，免輸入啟動詞。
- 原生互動表單不可用時，改用一次填寫的結構化聊天表單；題數控制採緊湊下拉或步進器。
- 建立規劃版與定稿版雙向細目表。
- 雙向細目表包含教材比例分佈表、教材 × 認知層次矩陣及逐題追溯明細。
- 依老師提供的題目格式參考統一題幹、選項、大題型標題與作答說明的呈現慣例，不沿用參考題目內容。
- 支援教師指定單元／活動平均或按比例配分；確保各範圍都有題，並於藍圖與定稿中核算理想／實際分數及差異。
- 支援教師設定每個獨立計分小題的最低／最高配分，並在題目審查與 `.xlsx` 統計表中逐題驗證；有多個上限時採較嚴格者。
- 教師指定單題配分和大題總分後，依指定值推算題數並重配各題型權重；任何題數或配分異動都重算題型小計、活動配分與全卷總分，確認標題和統計表一致。
- 填充題可整合為一個共同生活情境題組；各空格仍獨立計分並保留活動歸屬，題組小計由全卷權重核定。
- 連連看圖片逐張上下排列；每張圖右側與甲、乙等選項左側設黑色連線點，中央留白供直尺連線，版面維持一般欄寬並優先利用第一頁留白。
- 題幹盡量使用有助理解和作答的教室或生活情境；圖片不重複題號、題目名稱及題幹已提供的答案提示。
- 支援依參考包規劃空白作答卡、完整教師詳解版及精簡答案版等選配輸出，並驗證用途、答案對應與配分一致。
- 產生具合理誘答力的單選題、具辨識力的是非題，以及配合、連連看、勾選、看圖回答等多樣題型。
- 檢查選擇題答案位置、是非題正誤比例及排列規律。
- 題型大標題統一採「題型：作答指示。（每題／每格配分，共大題分數）」格式，清楚標出作答方法、單位配分與大題總分；不在每題題幹後重複加註括號配分。
- 開放作答題統一列明各題小題數、每小題配分與該題小計，並將答案欄依序標示及分行；看圖回答題依提示、圖片、答案欄的順序排版，客觀題維持專用作答形式。
- 大題標題與第一題及其必要作答材料保持同欄，避免標題留在欄尾、題目移到下一欄。
- 單選題固定以圈號 ①②③④ 標示選項，中文標點與雙欄排版依教師提供的版面參考統一檢核。
- 定期評量遵循年段字級、題目不拆欄、作答空間、圖表清晰、難度適切與試卷保密規範。
- 以獨立 Reviewer 重新檢查正確性、唯一答案、難度、閱讀負荷、公平性與素養層級。
- 生成後重新渲染驗證版面、題號、配分與跨文件一致性；任何偏離已確認規格的輸出都必須重做。
- 驗證以逐輪紀錄、修正、重建、回歸重驗的方式執行，直到已確認的輸出要求通過；缺少來源或無法查證的部分維持 REVIEW。
- 產生總分 100 分的空白卷、答案卷及最終版雙向細目表。
- 額外交付 `.xlsx` 出卷統計分析表，逐個計分題／小題列出大題與局部題號、主要題型、所屬單元／活動及配分，另彙總各題型與各活動分數。
- 以公式核算逐題、題型與活動配分，統計表另含「活動配分比例」餅圖工作表；重新開啟活頁簿驗證分數、占比總和100%及逐題配分範圍。
- 單選題與是非題不使用圖片；連連看必須同時有圖片與文字，採白底高對比圖像並保留中央連線空間，不預畫配對線。
- 試卷圖片採白底、高對比、適合黑白列印；依題意選用簡潔線稿或低墨量寫實圖，參照教材重新製作，不直接複製。圖片中若有人物，使用東亞面孔或 Q 版人物。
- 圖中文字、標籤、刻度需大而清楚、深色高對比，並按實際列印尺寸檢查；圖表優先用原生或可編輯圖形製作，避免 AI 圖中文字與數據失真。
- 空白卷、答案卷與雙向細目表固定輸出為 DOCX；空白卷與答案卷本體為 A3 直式正反兩面、恰好 2 頁。答案卷答案直接填入作答括號／空格、連連看直接畫線，開放題答案寫在指定答案欄，不插入題幹中。
- 試卷檔名維持既有主體格式，只在檔名主體後加 `yyyyMMdd_HHmmss` 本地時間戳並使用 `.docx` 副檔名；同批共用時間戳、重新生成不覆寫舊檔。
- 每頁題目區使用雙欄與中央隔線；開放題每題至多 4 分並留至少 2–3 行答案底線，底線行距加大以利書寫；連連看標註「請用直尺連線作答」。
- 是非題每題僅有一個判斷敘述，只要求圈選「○」或「×」；圈選指示放在大題標題，不在各題題幹重複，也不附加訂正或填充作答。
- 填充題的作答空格須使用空白括號，不得把「（1）」「（2）」等序號直接當成空格；子題編號應放在括號外。
- 題號前作答括號採窄空格；題幹、選項及續行採清楚的懸掛縮排，續行對齊題目文字起點，所有題型沿用一致的閱讀版式。
- 選擇題圈號與題幹同字級；勾選題使用特殊符號「✓／✗」，每個勾選1分，各敘述前留括號並以圈號編列，版式比照單選題；勾選題題幹、敘述與答案標記靠左對齊並共用一致左緣。石蕊試紙以文字標示紅／藍及酸鹼變色規則，不可只靠顏色。
- 每一大題題號獨立從 1 編起；答案附錄與雙向細目表以大題識別和局部題號對應。
- 可分析老師提供或具有明確授權的課本、習作、重點複習與隨堂演練；所有試題必須重新命題，參考圖必須重新繪製。
- 命題 115 學年度自然科時，可用[課程地圖](https://prayer168.github.io/science-course/)核對年級、學期、版本及單元／活動；其他學年度不套用此地圖，且每次命題均須由老師確認實際教學單元。

## 使用方式

每次開始建立新評量時，技能自動顯示 A–H 完整需求表單，預填訊息與附件可辨識的資料。表單涵蓋基本資料、範圍與教材、命題方向、題型多選、題數與配分、圖片與圖表、版面交付、特別要求；所有選項可自訂。一次送出後摘要需求並直接分析、命題、審查、輸出及驗證。互動表單不可用時，清楚說明限制並改用一次填寫的聊天表單。輸出資料夾路徑必填，檔案集中放入「評量標題_本地日期時間戳」資料夾。

## 標準流程

```text
INPUT → ANALYZE → CURRICULUM MAP → LEARNING OBJECTIVES
→ ASSESSMENT BLUEPRINT → QUESTION GENERATION
→ INDEPENDENT REVIEW → REVISE → FINAL VALIDATION → EXPORT
```

正式命題前具有兩個必要閘門：

一次送出後整理需求摘要，直接完成教材分析、課綱查證、命題、獨立審題、修訂、輸出與驗證；只有阻止命題／輸出的必要資料缺漏，或條件衝突且無可行調整時才集中追問，不要求逐題確認。

原生互動表單不可用時，Skill 會直接提供一次填寫的對話需求表單；不使用假按鈕，也不要求先同意文字備援。

## 正式交付成果

每份正式評量預設包含：

1. 空白卷：不顯示答案、解析或命題分析。
2. 答案卷：題序與空白卷一致，標示答案與必要解析。
3. 雙向細目表：逐題列出學習目標、課綱、題型、Bloom、難度、素養層級、情境、配分及品質旗標。

只有完成逐題審查、總分核對、答案分布檢查及三份成果一致性驗證後，才能標示 **Assessment Ready**。

## 題型代碼

- A：單選、是非、配合、填充、連連看、勾選。
- B：情境、科普閱讀、圖表判讀、資料分析、生活應用、跨領域、問題解決、看圖回答問題。
- C：推論、解釋、論證、開放、實驗設計、錯誤分析、證據判斷、創造設計。
- D1：AI 依年段、教材與評量目的配置題型；與其他代碼並選時，其他代碼視為必含題型。
- N1：AI 依年段、教材、總分與評量時間分配題數。
