# 108 課綱素養導向評量設計師

依教材、年段、評量目的與十二年國教課綱，設計或審查可追溯、可驗證、可直接輸出的素養導向評量。

目前版本：**2.4.1**（2026-09-28）

## 主要功能

- 分析教材核心概念、能力、迷思與評量邊界。
- 查證並對應十二年國教課綱、學習表現、學習內容與核心素養。
- 先完成可複選的題型設定，再逐一取得各題型題數或 AI 自動配置授權。
- 新評量各階段以可送出的互動選單／按鈕引導；題數使用每類一列的緊湊下拉或加減步進器，不再要求逐步輸入提示詞或「繼續」，也不會展開冗長數字選項清單。
- 建立規劃版與定稿版雙向細目表。
- 雙向細目表包含教材比例分佈表、教材 × 認知層次矩陣及逐題追溯明細。
- 支援依參考包規劃空白作答卡、完整教師詳解版及精簡答案版等選配輸出，並驗證用途、答案對應與配分一致。
- 產生具合理誘答力的單選題、具辨識力的是非題，以及配合、連連看、勾選、看圖回答等多樣題型。
- 檢查選擇題答案位置、是非題正誤比例及排列規律。
- 單選題固定以圈號 ①②③④ 標示選項，中文標點與雙欄排版依教師提供的版面參考統一檢核。
- 定期評量遵循年段字級、題目不拆欄、作答空間、圖表清晰、難度適切與試卷保密規範。
- 以獨立 Reviewer 重新檢查正確性、唯一答案、難度、閱讀負荷、公平性與素養層級。
- 生成後重新渲染驗證版面、題號、配分與跨文件一致性；任何偏離已確認規格的輸出都必須重做。
- 驗證以逐輪紀錄、修正、重建、回歸重驗的方式執行，直到已確認的輸出要求通過；缺少來源或無法查證的部分維持 REVIEW。
- 產生總分 100 分的空白卷、答案卷及最終版雙向細目表。
- 單選題與是非題不使用圖片；連連看與看圖回答須具備清晰視覺材料，閱讀及其他適合題型可按需生成可影印的黑白線條圖。
- DOCX／PDF 的空白卷與標答版試卷本體固定輸出為 A3 直式正反兩面、恰好 2 頁。
- 每一大題題號獨立從 1 編起；答案附錄與雙向細目表以大題識別和局部題號對應。
- 可分析老師提供或具有明確授權的課本、習作、重點複習與隨堂演練；所有試題必須重新命題，參考圖必須重新繪製。
- 命題 115 學年度自然科時，可用[課程地圖](https://prayer168.github.io/science-course/)核對年級、學期、版本及單元／活動；其他學年度不套用此地圖，且每次命題均須由老師確認實際教學單元。

## 使用方式

在 Codex 中輸入：

```text
使用 $competency-based-assessment-designer，依教材與十二年國教課綱設計一份素養導向評量。
```

也可直接提供教材、試卷、圖片、PDF、DOCX、PPTX、網頁或單元名稱。Skill 會以互動選單／按鈕依序引導基本資料、範圍、用途、題型、題數、難度與素養濃度，並保留已提交的設定。

## 標準流程

```text
INPUT → ANALYZE → CURRICULUM MAP → LEARNING OBJECTIVES
→ ASSESSMENT BLUEPRINT → QUESTION GENERATION
→ INDEPENDENT REVIEW → REVISE → FINAL VALIDATION → EXPORT
```

正式命題前具有兩個必要閘門：

1. 老師以互動多選器選擇題型；數字選單逐類設定題數，或點選授權 AI 自動分配。
2. 老師以互動選單確認教材範圍、邊界與輸出選項；已明確提供的資料不重問。

若原生互動元件不可用，Skill 會先明確告知介面限制並詢問是否同意一次性文字備援；不會把只保存而不回傳選取狀態的表單當成完成。

## 正式交付成果

每份正式評量預設包含：

1. 空白卷：不顯示答案、解析或命題分析。
2. 答案卷：題序與空白卷一致，標示答案與必要解析。
3. 雙向細目表：逐題列出學習目標、課綱、題型、Bloom、難度、素養層級、情境、配分及品質旗標。

只有完成逐題審查、總分核對、答案分布檢查及三份成果一致性驗證後，才能標示 **Assessment Ready**。

## 題型代碼

- A：單選、是非、配合、填充、連連看、勾選。
- B：情境、閱讀理解、圖表判讀、資料分析、生活應用、跨領域、問題解決、看圖回答問題。
- C：推論、解釋、論證、開放、實驗設計、錯誤分析、證據判斷、創造設計。
- D1：AI 依年段、教材與評量目的配置題型；與其他代碼並選時，其他代碼視為必含題型。
- N1：AI 依年段、教材、總分與評量時間分配題數。

## 授權與限制

課綱代碼、教材內容、法規及時效性資料必須使用正式來源查證。教材證據不足時，Skill 會標示待確認或 REVIEW，不會猜測正式內容。
