# 課綱對應與可評量學習目標

## 查證原則

依「年段＋領域＋單元＋教材內容」查找適用的十二年國教資料。來源優先序：

1. 教育部。
2. 國家教育研究院。
3. 正式十二年國教課程綱要文件。
4. 政府教育機構資料。
5. 可信教材或教育資料庫。

對可能更新或無法確定的資訊進行查證。記錄文件名稱、發布機構、適用版本／日期、頁碼或段落（可取得時）及連結。網路搜尋結果摘要不是正式依據，應開啟原始文件核對。

禁止自行虛構核心素養、學習表現或學習內容代碼。只有文字內涵可確認但代碼不能確認時，分開呈現：

```text
課綱內涵：……
課綱代碼：⚠ 待正式資料查證
```

## Curriculum Map

至少整理：

- 總綱核心素養。
- 領域核心素養。
- 學習表現。
- 學習內容。
- 學習重點。
- 可實際評量的能力。
- 與教材內容的對應證據。

避免只羅列代碼。說明每項課綱內容如何被教材教到，以及可由哪些表現或作品觀察。

## 可評量的學習目標

把教材與課綱轉為可觀察、可判定的表現，使用「學生能＋行動動詞＋內容／條件＋品質或證據」結構。

避免模糊目標，例如「了解植物」。改為：

- 學生能根據觀察資料比較不同植物構造。
- 學生能利用證據解釋植物構造與功能的關係。
- 學生能根據實驗結果判斷影響植物生長的可能因素。

每個主要學習目標至少配置一題；若無法在本次題數內覆蓋，應在藍圖中顯示缺口，不可假稱已涵蓋。

## Bloom 修訂版

使用以下層級並同時顯示中文：

1. Remember／記憶
2. Understand／理解
3. Apply／應用
4. Analyze／分析
5. Evaluate／評鑑
6. Create／創造

Bloom 由學生完成題目所需的最高必要認知操作判定，不由題型或篇幅判定。選擇題也可能需要分析；開放題也可能只在回憶。不得為追求高層次而超出年齡發展或教學內容。

## 對應完整性檢查

在進入命題前確認：

- 每個目標都有教材或課綱依據。
- 每個題目預計測量的目標可由作答證據判定。
- 課綱、目標與題目不只是關鍵字相似，而有能力層面的對應。
- 跨領域內容已清楚標示，且未讓未教知識成為作答門檻。
