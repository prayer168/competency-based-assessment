# 評量輸出與題庫結構

## 正式評量的必要交付套件

每次產生正式評量，預設同時交付以下三項。除非使用者明確只要求其中部分成果，不得省略。

正式檔案固定輸出為 `.docx`：空白卷、答案卷、雙向細目表及必要的教師附錄各自獨立成檔。只有老師明確要求時才額外轉出其他格式。空白卷與答案卷套用 [exam-layout-template.md](exam-layout-template.md) 的 A3 雙欄抬頭與卷面編排，試卷本體各自恰好 2 頁，對應一張 A3 紙正反兩面；雙向細目表是教師分析文件，不計入這 2 頁，不套用試卷雙欄版面，以可讀性優先。

每份正式評量另須交付一份 `.xlsx` 出卷統計分析表，作為唯一指定的非 DOCX 必要成果；此檔不能取代三份 DOCX。格式、欄位、統計公式與總分驗證依 [score-analysis-workbook.md](score-analysis-workbook.md)。

檔名沿用既有命名主體（如 `{評量名稱}-空白卷`、`{評量名稱}-答案卷`、`{評量名稱}-雙向細目表`），於主體後、`.docx` 前加入本地生成時間戳 `yyyyMMdd_HHmmss`，例如 `{評量名稱}-空白卷_20260928_153000.docx`。同一批輸出共用同一時間戳；重生檔案建立新檔，不覆寫舊版，不另改原本的名稱次序或命名結構。

### 1. 空白卷（學生作答版）

只顯示標題、總分 100 分、各大題小計、逐題配分、作答說明、題目、必要圖表與作答區。不得出現答案、解析、Bloom、難度、素養層級、迷思或審查註記。

### 2. 答案卷

完整保留空白卷的標題、總分、各大題小計、題號、題序、題幹、選項、圖表、逐題配分與兩頁版面結構，並清楚標示每題正確答案。客觀題標示正確選項或正誤；開放題在試卷本體標示精簡參考答案或評分要點。完整解析、評分規準與部分給分原則放入試卷後的教師附錄，規準分數合計須等於該題配分；附錄不計入兩頁試卷本體。不得因加入解析而改動原題或讓試卷本體增加頁數。

學習目標、課綱、Bloom、難度、素養 Level、迷思概念與 Reviewer 註記等命題分析，預設放在完整命題報告或答案卷之後的教師附錄，不插入空白卷。

### 3. 雙向細目表

依已通過最終審查的定稿題目重新產生，不得直接沿用命題前的規劃草稿。至少逐題列出題號、教學內容、學習目標、課綱、題型、Bloom、預期／審查後難度、素養層級、情境、配分與品質旗標；表末附各項實際分布及未涵蓋目標。

教師提供的表格格式要求另依 [blueprint-template.md](blueprint-template.md)：同一份正式細目表須先列基本資料及「教材比例分佈表」（單元、上課節數、理想配分、實際配分、備註），再列「試題分析雙向細目表」（教材單元 × 記憶／了解／應用／分析／評鑑／創作），並附逐題追溯明細。分布表的實際配分與認知矩陣均由最終試題和逐題分數計算，不以規劃數字取代。

雙向細目表屬教師文件，不放入空白卷。若輸出為檔案，固定建立獨立 `.docx` 檔；只有老師明確指定時才額外提供其他格式。

### 可選的多檔案輸出

收到多檔案輸出參考包時，依 [archive-output-style-reference.md](archive-output-style-reference.md) 區分各文件功能。老師要求或作答情境確有需要時，可另加：

- **空白作答卡／答案紙**：只提供按大題組織的答案格或書寫格，題號須能回指試卷；這不是學生空白題目卷，也不是答案卷。
- **題目與完整詳解教師版**：逐題附答案、解析和有查證依據的教學分析資訊，僅教師使用。
- **精簡答案與詳解**：按大題及局部題號快速查答，屬逐題詳解之外的額外版本。

以上選配檔案不能取代空白卷、答案卷與雙向細目表；不得把家長簽名欄、成績區間、日期等樣本欄位自動加到每份試卷。各文件標示學生／教師用途並分開命名，題目、答案、圖表與配分均由同一份定稿資料生成。

### 三項成果一致性

- 兩份試卷必須由同一份已驗證的題目資料產生。
- 雙向細目表也必須由同一份最終題目資料產生，每一題及具獨立目標的小題都能對應回試卷。
- 題目、選項、圖表、大題順序、各大題內由 1 起編的局部題號、配分及頁面中的作答條件必須一致；差異只限答案、解析、評分規準及教師註記。內部識別碼全卷唯一，細目表／附錄以大題識別加局部題號引用。
- 任一題在輸出階段修正後，空白卷、答案卷與雙向細目表都要重新產生並再次比對，不可只修改其中一項。
- 產生實體檔案時清楚分開命名，保留既有檔名主體並加本地時間戳，例如 `單元評量-空白卷_20260928_153000.docx`、`單元評量-答案卷_20260928_153000.docx` 與 `單元評量-雙向細目表_20260928_153000.docx`；不可只在同一檔案中混合而讓學生誤見答案，除非使用者明確要求合併。
- 直接在對話中輸出時，以「空白卷」、「答案卷」與「雙向細目表」三個明確區段完整呈現。

### 完整命題報告

此為上述必要交付套件之外的選配文件。依需要包含：基本設定、教材分析、課綱分析、評量範圍、學習目標、雙向細目表、正式試題、解答、Reviewer 報告、難度分析、素養分析、題型分析、修正紀錄與最終品質報告。

文件類交付預設且必須使用 DOCX；沒有額外要求時不可把 PDF、Markdown、HTML、PPTX、JSON、CSV 或題庫匯出取代三份 DOCX 成果。若老師另外明確要求其他格式，再由通過審查的同一份題目資料加做，避免空白卷與答案卷的題目、答案或題號漂移。

## 最終品質摘要

至少列出：

- 教學重點涵蓋率：`有題目且具足夠作答證據的主要重點數 ÷ 本次主要重點總數`。同時列出未涵蓋項目，避免百分比掩蓋缺口。
- 課綱涵蓋：列主要對應與查證狀態。
- Bloom 分布：以題數計算；若各題配分差異大，可另列配分加權分布。
- 配分分布：列出各大題小計、主要學習目標的分數與比例，並確認全卷合計為 100 分。
- 難度分布：只用 `difficulty_reviewed`。
- 素養層級、題型、圖像題、高層次題比例。
- 題型題數核對：逐項列出老師指定或 AI 配置的目標題數、最終實際題數與差異。
- 客觀題答案分布：單選題以實際印出的 ①、②、③、④ 標籤列各答案位置次數，是非題列正誤次數；有 A7 勾選題時，另列各題正確勾選項目數與漏選／誤選計分概況，不計單選題位置分布。
- 品質旗標數量及尚待教師確認事項。
- 素養評級 A–E 與理由。

所有百分比說明分母，四捨五入造成總和不為 100% 時加註。多小題可依其是否具獨立學習目標與配分，事先決定以小題或大題為計算單位並保持一致。

## 題庫 JSON

長期題庫每題至少保留：

```json
{
  "question_id": "",
  "grade": "",
  "subject": "",
  "unit": "",
  "learning_objective": "",
  "curriculum_reference": [],
  "question_type": "",
  "points": 0,
  "bloom_level": "",
  "competency_level": 0,
  "expected_difficulty": "",
  "reviewed_difficulty": "",
  "misconception_target": "",
  "context_type": "",
  "visual_allowed": false,
  "visual_required": false,
  "visual_role": "",
  "visual_type": "",
  "visual_asset_reference": null,
  "visual_style": "",
  "visual_prompt": "",
  "visual_alt_text": "",
  "visual_review_status": "",
  "quality_flag": "",
  "question": "",
  "choices": [],
  "matching_pairs": [],
  "checkbox_items": [],
  "correct_answer": "",
  "explanation": ""
}
```

題型專屬資料使用方式：

- A6 連連看：`matching_pairs` 逐組保存左右項目、正確配對及該組分數，確保答案卷、部分給分與題數一致。
- A7 勾選題：`checkbox_items` 逐項保存候選物件／資料／行動、是否符合題目條件及配分；`correct_answer` 保留完整標準勾選集合，並由評分規準定義漏選與誤選如何給分。
- B8 看圖回答問題：使用既有 `visual_*` 欄位描述圖像功能及檢查狀態；`visual_asset_reference` 可記錄對應圖檔路徑或來源識別。若 schema 或匯出格式尚未支援新欄位，需保留為可追溯附加欄位，不可把 A6／A7 答案壓成無法驗證的純文字。

建議另保留 `source_material_reference`、`curriculum_verification`、`review_notes`、`rubric`、`points`、`revision_history` 與 `version`，以支援追溯和修訂。不得在 JSON 中把未知值寫成猜測；使用 `null`、空陣列或清楚的待查狀態。

## 修正紀錄

對實質修改保留：題號、原始問題、問題類型、修改內容、修改理由、重新審查結果。若輸出公開學生卷，修正紀錄只放在教師版或完整報告。

## Assessment Ready

只有在以下條件全部成立時標記：

- 沒有 `🔴 REVISE`。
- 答案、詳解與評分規準一致。
- 所有題目已合理配分，各大題小計與逐題分數加總正好為 100 分。
- 空白卷與答案卷均已產生；空白卷不含答案，答案卷正確標示所有答案。
- 最終版雙向細目表已產生，且反映修訂後的實際題目與審查結果。
- 空白卷、答案卷與雙向細目表的題號、題序、學習目標及配分已逐項比對一致。
- 生成後已將實際檔案渲染逐頁核對；版型、題號重設、作答空間、頁數、配分與指定格式全數通過，否則已重建並重新驗證。
- 課綱查證狀態已揭露。
- 主要學習目標涵蓋缺口已處理或明示。
- 實際分布已重新計算。
- 每個已選主要題型的實際題數均等於目標題數，且未加入未選題型。
- 選擇題選項皆與題幹相關且具合理誘答力；單選題使用 ①②③④ 圈號，答案位置與是非題正誤分布已檢查並避免可預測規律。
- 單選題與是非題未使用圖片；其他圖像題皆有必要的評量功能，生成圖已通過內容正確性、答案洩漏、圖文分離、黑白列印可讀性檢核。
- DOCX 已逐頁渲染，紙張為 A3 直式；空白卷與標答版試卷本體各恰好 2 頁，且兩頁均有實際試題、無裁切或錯欄。
- 學生版未洩漏答案或命題分析。
