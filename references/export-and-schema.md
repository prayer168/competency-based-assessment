# 評量輸出與題庫結構

## 正式評量的必要交付套件

每次產生正式評量，預設同時交付以下三項。除非使用者明確只要求其中部分成果，不得省略。

### 1. 空白卷（學生作答版）

只顯示標題、總分 100 分、各大題小計、逐題配分、作答說明、題目、必要圖表與作答區。不得出現答案、解析、Bloom、難度、素養層級、迷思或審查註記。

### 2. 答案卷

完整保留空白卷的標題、總分、各大題小計、題號、題序、題幹、選項、圖表、逐題配分與版面結構，並清楚標示每題正確答案。客觀題標示正確選項或正誤；開放題提供參考答案、評分規準與部分給分原則，規準分數合計須等於該題配分。可附簡明解析，但不得因加入解析而改動原題。

學習目標、課綱、Bloom、難度、素養 Level、迷思概念與 Reviewer 註記等命題分析，預設放在完整命題報告或答案卷之後的教師附錄，不插入空白卷。

### 3. 雙向細目表

依已通過最終審查的定稿題目重新產生，不得直接沿用命題前的規劃草稿。至少逐題列出題號、教學內容、學習目標、課綱、題型、Bloom、預期／審查後難度、素養層級、情境、配分與品質旗標；表末附各項實際分布及未涵蓋目標。

雙向細目表屬教師文件，不放入空白卷。若輸出為檔案，預設建立獨立檔案，例如 `單元評量-雙向細目表.xlsx`、`.docx` 或使用者指定的格式。

### 三項成果一致性

- 兩份試卷必須由同一份已驗證的題目資料產生。
- 雙向細目表也必須由同一份最終題目資料產生，每一題及具獨立目標的小題都能對應回試卷。
- 題目、選項、圖表、題序、配分及頁面中的作答條件必須一致；差異只限答案、解析、評分規準及教師註記。
- 任一題在輸出階段修正後，空白卷、答案卷與雙向細目表都要重新產生並再次比對，不可只修改其中一項。
- 產生實體檔案時清楚分開命名，例如 `單元評量-空白卷.pdf`、`單元評量-答案卷.pdf` 與 `單元評量-雙向細目表.xlsx`；不可只在同一檔案中混合而讓學生誤見答案，除非使用者明確要求合併。
- 直接在對話中輸出時，以「空白卷」、「答案卷」與「雙向細目表」三個明確區段完整呈現。

### 完整命題報告

此為上述必要交付套件之外的選配文件。依需要包含：基本設定、教材分析、課綱分析、評量範圍、學習目標、雙向細目表、正式試題、解答、Reviewer 報告、難度分析、素養分析、題型分析、修正紀錄與最終品質報告。

輸出前確認使用者需要 Markdown、DOCX、PDF、HTML、PPTX、JSON、CSV 或題庫格式。若產生文件檔，仍以通過審查的同一份題目資料為單一來源，避免空白卷與答案卷的題目、答案或題號漂移。

## 最終品質摘要

至少列出：

- 教學重點涵蓋率：`有題目且具足夠作答證據的主要重點數 ÷ 本次主要重點總數`。同時列出未涵蓋項目，避免百分比掩蓋缺口。
- 課綱涵蓋：列主要對應與查證狀態。
- Bloom 分布：以題數計算；若各題配分差異大，可另列配分加權分布。
- 配分分布：列出各大題小計、主要學習目標的分數與比例，並確認全卷合計為 100 分。
- 難度分布：只用 `difficulty_reviewed`。
- 素養層級、題型、圖像題、高層次題比例。
- 題型題數核對：逐項列出老師指定或 AI 配置的目標題數、最終實際題數與差異。
- 客觀題答案分布：單選題各答案位置次數、是非題正誤次數；有複選題時另列各位置成為正解的次數與重複組合。
- 品質旗標數量及尚待教師確認事項。
- 素養評級 A–E 與理由。

所有百分比說明分母，四捨五入造成總和不為 100% 時加註。多小題可依其是否具獨立學習目標與配分，事先決定以小題或大題為計算單位並保持一致。

## 題庫 JSON

長期題庫每題至少保留：

```json
{
  "question_id": "",
  "grade": "",
  "subject": "",
  "unit": "",
  "learning_objective": "",
  "curriculum_reference": [],
  "question_type": "",
  "points": 0,
  "bloom_level": "",
  "competency_level": 0,
  "expected_difficulty": "",
  "reviewed_difficulty": "",
  "misconception_target": "",
  "context_type": "",
  "visual_required": false,
  "visual_type": "",
  "visual_prompt": "",
  "quality_flag": "",
  "question": "",
  "choices": [],
  "correct_answer": "",
  "explanation": ""
}
```

建議另保留 `source_material_reference`、`curriculum_verification`、`review_notes`、`rubric`、`points`、`revision_history` 與 `version`，以支援追溯和修訂。不得在 JSON 中把未知值寫成猜測；使用 `null`、空陣列或清楚的待查狀態。

## 修正紀錄

對實質修改保留：題號、原始問題、問題類型、修改內容、修改理由、重新審查結果。若輸出公開學生卷，修正紀錄只放在教師版或完整報告。

## Assessment Ready

只有在以下條件全部成立時標記：

- 沒有 `🔴 REVISE`。
- 答案、詳解與評分規準一致。
- 所有題目已合理配分，各大題小計與逐題分數加總正好為 100 分。
- 空白卷與答案卷均已產生；空白卷不含答案，答案卷正確標示所有答案。
- 最終版雙向細目表已產生，且反映修訂後的實際題目與審查結果。
- 空白卷、答案卷與雙向細目表的題號、題序、學習目標及配分已逐項比對一致。
- 課綱查證狀態已揭露。
- 主要學習目標涵蓋缺口已處理或明示。
- 實際分布已重新計算。
- 每個已選主要題型的實際題數均等於目標題數，且未加入未選題型。
- 選擇題選項皆與題幹相關且具合理誘答力，答案位置與是非題正誤分布已檢查並避免可預測規律。
- 學生版未洩漏答案或命題分析。
