# 出卷統計分析表（XLSX）

本檔定義正式評量必交的 `.xlsx` 出卷統計分析表。它是教師命題分析文件，不取代空白卷、答案卷或雙向細目表。工作簿必須由同一份最終定稿題目資料產生，不能以規劃草稿的數字冒充定稿結果。

## 必要工作表

1. **逐題統計**：每個可獨立作答、獨立配分的題目／小題一列，至少包含「大題識別、大題內題號、內部題目 ID、主要題型、單元名稱、活動名稱、學習重點、配分」。情境／圖表等標籤可另列為次要特徵，但一個計分單位只能有一個主要題型、主要活動歸屬，避免重複加總。
2. **題型統計**：逐主要題型彙總目標題數、實際題數、配分小計與全卷占比；AI 自動配置的目標題數和實際題數須可比較。
3. **活動配分統計**：依本次確認的每個單元／活動列出理想配分、實際配分、分差、題數與占總分比例；理想配分依教師指定比例或一般配分原則記錄。
4. **總分驗證**：列出逐題配分合計、題型小計合計、活動小計合計、試卷設定總分、逐題加總與設定總分的差額、驗證狀態。以公式從逐題表與彙總表計算，不手動填入固定的「100」作為加總結果。
5. **活動配分比例**：使用六個單元活動的實際配分製作餅圖，呈現各活動占全卷配分的比例；圖例或標籤須可辨識活動名稱，並標示比例（可同時標配分）。圖表直接連結「活動配分統計」工作表的活動及實際配分，避免重複輸入數據；檢查六個比例合計為 100%。

## 計算與一致性要求

- 逐題統計每列映射回空白卷、答案卷及雙向細目表的唯一題號；拆分小題時依其實際獨立配分逐列登錄。
- 老師指定每小題配分範圍時，逐題表保留指定最低／最高分及範圍驗證欄，以公式檢查每個配分均符合限制；若有數個上限，依較嚴格者驗證。總分通過不得抵銷單題超額。
- 題型彙總與活動彙總均由逐題資料公式加總；所有小計合計須等於逐題配分總和和試卷設定總分，預設為 100 分。
- 公式驗證結果必須清楚顯示 `通過` 或 `未通過`。只有差額為 0、題型／活動彙總與逐題合計一致且所有題號可追溯時，總分驗證才可通過。
- 依試卷版面清楚呈現標題列、欄名、單位及合計；凍結標題列、套用可篩選範圍、合理欄寬及數字格式，避免截斷題型／活動文字。餅圖僅呈現活動配分比例，不加入與命題統計無關的圖表或裝飾。
- 產生後重新開啟工作簿，檢查公式、儲存格值、彙總、題號追溯與總分；若計算引擎可用，重算後讀取公式結果。僅在 Excel 顯示原始公式文字或結果錯誤時，不得宣稱核算通過。
- 檔案以 `.xlsx` 交付，檔名沿用本次評量名稱並附與同批 DOCX 相同的本地時間戳；重新生成時不得覆寫舊檔。與同批 DOCX、雙向細目表及附件一起放入以「評量標題_yyyyMMdd_HHmmss」命名的新資料夾，標題包含學年度／學期、年段、領域與用途。
